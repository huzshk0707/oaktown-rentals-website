## Installation and permissions review

- No repository install scripts, global hooks or global skill installers were run. No third-party template app was started with production credentials.
- Hallmark's static checker is dependency-free Node and writes local review reports. Its render checker requires Puppeteer/Chromium. Installed pinned `puppeteer-core@24.31.0` into `/tmp/oaktown-review-tools` with `--ignore-scripts`; used the already installed Chromium with the same `--no-sandbox` mode as the repository's existing browser tests. The upstream files were not patched.
- Impeccable's launcher was inspected before execution. It downloads a pinned engine and verifies SHA-256 against its checked-in manifest. Its cache was confined to `/tmp/oaktown-impeccable`. Context and source detection ran. Its own rendered launcher failed because of the container's Chromium sandbox configuration; this is reported, not counted as a pass.
- `axe-core@4.11.0` was installed into the same temporary review-tool directory with lifecycle scripts disabled, and injected only into local test pages. It is not shipped to visitors.
- No runtime dependencies, lockfiles, Cloudflare configuration, credentials, auth settings, migrations or production property records changed. The new test scripts use the existing Playwright dependency.
- The initial environment denied production preview, photography CDN and GitHub API requests. After the user applied the environment permissions, these services became reachable. A read-only public API snapshot and TLS-verified source-photo downloads support the refreshed review; the browser proxy CA limitation is documented in validation.

## Applying the tools with judgment

Hallmark's checked rules flag the retained legacy CSS (including rules overridden by the scoped redesign), its own required stamp conventions, preserved paragraph lengths, and unavailable external imagery. Its combined final scan is **not green**. Impeccable's source scan similarly sees unused dark/gradient declarations from the retained styles. These results are recorded as review evidence, not an invented quality score. Rendered browser checks, axe, the existing test suite and independent review establish the behaviors actually verified; real-photo composition and all 39 gallery sources have since been checked. Owner approval and native Safari/Firefox testing remain open.
